Rubro: Logística (Grupo 6)

Optimización de Entregas con TMS

Caso Práctico 02: Implementación de un proceso BPM para la mejora de gestión de flotas y distribución usando Tecnologías de la Información.

Planteamiento del Caso

La Organización

"LogiFast Perú S.A." es una empresa de logística de última milla. Actualmente, su proceso de enrutamiento y asignación de despachos se realiza de forma manual mediante hojas de cálculo (Excel).

El Problema

  • Retrasos en las entregas por rutas ineficientes.
  • Alta carga operativa de los asesores, generando cuellos de botella.
  • Falta de visibilidad del estado de entrega para el cliente final.
  • Altos costos de combustible.

La Solución Tecnológica (TI)

Implementar un Sistema de Gestión de Transporte (TMS) basado en la nube con telemetría GPS y algoritmos para el cálculo automático de rutas.

Ciclo de Vida BPM

  • 1. Diseño: Se identifica el cuello de botella en la asignación manual. Se propone integrar el ERP con un TMS para automatizar el ruteo.
  • 2. Modelado: Se diseña el nuevo flujo de trabajo (ver diagrama inferior) definiendo las interacciones entre Cliente, Sistema TMS y Conductor.
  • 3. Ejecución: Se despliega la aplicación móvil para los conductores y se enlazan las APIs de notificaciones (SMS/WhatsApp) para el cliente.
  • 4. Monitoreo: Se definen KPIs de control: % de entregas perfectas (OTIF) y Ahorro de combustible por ruta.
  • 5. Optimización: Analizar la data histórica usando Machine Learning para predecir tráfico y reducir tiempos muertos futuros.
